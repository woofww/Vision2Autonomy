# Vision2Autonomy 学习路线

[English](roadmap.md) | [简体中文](roadmap.zh-CN.md)

项目采用小步、可验证的里程碑推进。每一章都必须包含原理讲解、从零实现、可复现实验、参考图片和自动化测试。

## 第一阶段：图像处理基础

- 图像数组、数值范围与数据类型
- 灰度图与颜色空间
- 卷积、相关运算与边界填充
- Gaussian 平滑与可分离卷积
- Sobel 梯度
- 完整 Canny 边缘检测

阶段成果：能够解释并实现一条不依赖 `cv2.Canny` 的边缘检测流水线，并通过测试验证每个步骤。

## 第二阶段：传统计算机视觉

- Harris 角点检测（已完成）
- FAST 等角点检测
- 局部补丁描述、最近邻匹配与比率检验（已完成）
- 归一化 DLT 与 RANSAC Homography（已完成）
- Hough 直线检测与数学形态学（已完成）
- 轮廓分析
- Lucas–Kanade 光流与目标跟踪（已完成）
- 稠密光流与长时跟踪扩展

阶段成果：建立可以处理结构、特征和运动信息的传统视觉工具箱。

## 第三阶段：相机与多视图几何

- 针孔相机模型与坐标变换（已完成）
- 相机内外参与畸变校正（已完成）· [第 08 章](../chapters/08_camera_calibration/README.zh-CN.md)
- Homography 与透视变换
- 对极几何与基础矩阵（已完成）
- 双目三角化与深度敏感性（已完成）
- PnP、视觉里程计与轨迹评估

阶段成果：从二维像素恢复几何关系，为车道鸟瞰变换、距离估计和车辆运动分析建立基础。

## 第四阶段：深度视觉

- 神经网络、反向传播和卷积层基础
- PyTorch 数据管线与训练循环
- 图像分类与迁移学习
- 目标检测
- 语义分割与实例分割
- 单目深度估计
- 多任务学习、模型评估与误差分析

阶段成果：不仅能够训练模型，还能够解释数据、损失函数、指标和失败案例之间的关系。

## 第五阶段：自动驾驶视觉感知

- 车道线检测
- 可行驶区域分割
- 车辆、行人和骑行者检测
- 多目标跟踪
- 单目或双目距离估计
- 相机标定与鸟瞰视图
- 多任务感知与实时性能分析

最终综合项目以行车视频为输入，输出目标框、类别、跟踪 ID、轨迹、车道线、可行驶区域和距离信息，并报告准确率、延迟和吞吐量。

## 范围边界

当前路线的终点是自动驾驶视觉感知，而不是完整自动驾驶系统。定位、行为预测、路径规划和车辆控制会在感知主线成熟后作为独立扩展考虑，避免过早扩大范围而降低每一部分的完成质量。
