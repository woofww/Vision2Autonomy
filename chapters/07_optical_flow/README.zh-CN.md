# 第 07 章：光流与跟踪（Lucas-Kanade）

[English](README.md) | [简体中文](README.zh-CN.md)

> 单张图像告诉我们“物体在哪里”，连续两帧告诉我们“物体怎么动”：光流把像素差异变成运动场。

## 学习目标

- 写出亮度恒定假设，并推导它的线性化形式；
- 解释为什么一个方程无法确定两个运动分量（孔径问题）；
- 用窗口内的梯度累加构造 Lucas-Kanade 2×2 最小二乘系统；
- 把最小特征值解读为每个像素的可信度；
- 复现已知平移，并观察估计何时开始出现偏差；
- 把光流与驾驶场景中的跟踪、自车运动、运动目标线索联系起来。

## 1. 亮度恒定与线性化

假设场景点在运动过程中亮度不变：

```math
I(x, y, t) = I(x+u, y+v, t+1)
```

`t` 时刻位于 `(x, y)` 的像素，在 `t+1` 时刻移动到 `(x+u, y+v)`，其中 `(u, v)` 就是位移。对它做一阶泰勒展开，得到**光流约束方程**：

```math
I_x u + I_y v + I_t = 0
```

`I_x`、`I_y` 是空间梯度，`I_t` 是帧差，`(u, v)` 是待求量。这是一个含两个未知数的一个线性方程，因此每个像素只能约束沿其梯度方向的运动。

## 2. 孔径问题与可信度

单条边缘只在某个方向上有强梯度，因此只能确定**法向流**（垂直于边缘的运动），无法确定沿边缘的运动。平坦区域没有任何梯度，完全不提供约束。只有当局部窗口内存在两个不同方向的纹理时，`u` 和 `v` 才能同时确定。

局部结构张量刻画了这一点：

```math
A = \begin{bmatrix} \sum I_x^2 & \sum I_x I_y \\ \sum I_x I_y & \sum I_y^2 \end{bmatrix}
```

`A` 的较小特征值衡量窗口在两个方向上的纹理强度。特征值大意味着可信的光流；接近零意味着平坦区域或单条边缘，运动是模糊的。本章把这些像素标记为 `valid = False`。

![左图与带光流箭头的右图](../../docs/assets/chapter07_optical_flow.png)

带纹理的矩形向右下移动一个像素，圆形向左下移动一个像素。绿色箭头标记高可信光流，静止背景没有箭头。这正是驾驶场景中的两类运动线索：世界大部分静止，少数物体在运动。

## 3. Lucas-Kanade 最小二乘

假设 `w×w` 的小窗口内所有像素共享同一运动 `(u, v)`。每个像素贡献一个线性方程，窗口内共有 `w²` 个方程、两个未知数。最小二乘解为：

```math
\begin{bmatrix} \sum I_x^2 & \sum I_x I_y \\ \sum I_x I_y & \sum I_y^2 \end{bmatrix}
\begin{bmatrix} u \\ v \end{bmatrix}
=
-\begin{bmatrix} \sum I_x I_t \\ \sum I_y I_t \end{bmatrix}
```

```python
from vision2autonomy.motion import lucas_kanade_flow

result = lucas_kanade_flow(frame_a, frame_b, window_size=15)
u, v = result.flow[row, column]
confident = result.valid[row, column]
```

实现用两帧平均做中心差分得到空间梯度，用 `I_t = I_{t+1} - I_t` 得到时间梯度，再用均匀卷积核累加五个窗口和。每个像素的 2×2 系统有闭式解，可以完全向量化。

## 4. 什么会出错——以及为什么

参考场景专门让这些失败模式可见：

- **大位移破坏线性化。** 泰勒展开是局部的。长波长图案移动一个像素能精确恢复；短波长图案移动数像素则不行。真实系统用图像金字塔（由粗到细）处理大位移。
- **硬边缘和高频纹理使估计产生偏差。** 棋盘格或细条纹相对其周期移动了数像素，边缘处一阶模型失效，最小二乘解被拉向更小的值。
- **噪声会衰减估计。** 梯度中的测量噪声相当于自变量含误差，会把光流向零收缩。
- **纹理固定在图像坐标上会隐藏内部运动。** 如果图案不随物体移动，两帧之间只有遮挡边界在变化，物体内部看起来是静止的。正确的场景必须让纹理随物体一起平移。

这些失败不是单纯的 bug，而是课程内容：它们解释了为什么需要金字塔、稳健估计和严谨的数据采集。

## 6. 坐标、单位与参数

| 量 | 约定 | 常见错误 |
|---|---|---|
| 光流 `(u, v)` | 从 `t` 到 `t+1` 的位移，`(column, row)` | 弄反帧顺序或轴顺序 |
| 梯度 | 对两帧平均做中心差分 | 只用其中一帧的梯度，会引入偏差 |
| `I_t` | `I(x, y, t+1) - I(x, y, t)` | 写成 `I_t - I_{t+1}` 导致光流符号相反 |
| 可信度 | `A` 的较小特征值 | 把行列式或 `I_t` 大小当作可信度 |
| 窗口 | 奇数且 `>= 3` | 窗口小于预期位移 |
| 有效性 | 排除边界和低纹理像素 | 在平坦或一维区域盲目相信光流 |

## 7. 与自动驾驶的联系

光流是驾驶场景中连接几何与动力学的桥梁：

- **多目标跟踪：** 光流把车辆或行人跨帧关联起来，在检测之间形成平滑轨迹；
- **自车运动估计：** 相机移动时，静止世界产生的光流模式由相机运动决定，拟合该模式即得到视觉里程计；
- **运动目标分割：** 补偿自车运动后，剩余光流会突出独立运动的物体——横穿的行人或超车的车辆；
- **时间一致性：** 跨帧运动不一致的检测很可能是误检。

实际中的失败同样重要：车道线是几乎平行于自身运动方向的边缘（孔径问题），高速驾驶产生的大位移会击穿单尺度 Lucas-Kanade，遮挡边界会产生虚假光流。生产系统结合金字塔、RANSAC 等稳健估计和传感器融合来应对。
