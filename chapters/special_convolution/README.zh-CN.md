# 卷积特刊：从直觉、物理到图像

[English](README.md) | [简体中文](README.zh-CN.md)

> 目标不是让你记住一个公式，而是让你看到“卷积”两个字时，脑中能出现一幅明确的画面。

## 先给结论

卷积不等于时间演变，也不等于模糊。最统一的说法是：

> **卷积把同一条局部影响规则移动到每个位置，计算周围输入对当前位置的加权贡献。**

位置可以是时间、图像坐标、视频的时空坐标或三维体素。时间系统让“位置”变成过去与现在；图像处理让“位置”变成上下左右。

![从时间、空间和频率理解卷积](../../docs/assets/convolution_three_views.svg)

## 第一层：先把它当成“滑动加权求和”

假设一维信号是：

```text
x = [0, 0, 3, 0, 0]
```

规则是：一个输入除了影响当前位置，还以一半强度影响下一个位置：

```text
h = [1, 0.5]
```

数值 `3` 会产生一份平移后的响应：

```text
y = [0, 0, 3, 1.5, 0, 0]
```

如果输入中有很多非零值，每个输入都会产生一份缩放、平移后的 `h`，最后把它们全部相加。这就是卷积最物理的直觉：

```math
y[n]=\sum_k x[k]h[n-k]
```

公式中的每一项都可以读成：“第 `k` 个输入有多大”乘以“它对第 `n` 个输出能留下多大影响”。

## 第二层：为什么时间系统天然出现卷积？

考虑一个安静房间。拍一次手，麦克风不会只收到一个瞬时声音，还会收到墙壁反射产生的余响。把“单位拍手之后的完整余响”记作 `h(t)`。

如果在时刻 `τ` 拍手，余响会变成 `h(t-τ)`；如果拍手力度是 `x(τ)`，余响幅度就变成 `x(τ)h(t-τ)`。现实声音由无数时刻的微小输入组成，把所有余响相加：

```math
y(t)=\int_{-\infty}^{\infty}x(\tau)h(t-\tau)d\tau
```

因此，在**线性、时不变系统**中：

- 线性：输入相加，输出也相加；输入放大，输出同比放大；
- 时不变：今天的单位输入和明天的单位输入产生同样形状、只发生平移的响应；
- `h`：系统对单位脉冲的响应，即“它怎样记住一次输入”。

这时卷积确实描述“过去如何影响现在”。但时间含义来自系统和坐标轴，不是卷积符号本身。

## 第三层：为什么公式里要翻转？

卷积写作 `h[n-k]`，当我们让 `k` 从左到右变化时，相当于先把 `h` 翻转，再平移到 `n`。这个翻转让卷积具备重要的代数性质，例如：

```math
x*h=h*x
```

工程库经常直接滑动不翻转的核，那叫**互相关**：

```math
r[n]=\sum_k x[n+k]h[k]
```

在图像和深度学习中，人们常把互相关也称作“卷积”。如果核是左右对称的，例如 Gaussian 核，翻不翻结果相同；对于 Sobel 等非对称核，结果的方向或符号可能变化。

## 第四层：图像里没有时间，卷积在表达什么？

灰度图是二维空间函数 `I(x,y)`。图像卷积表示：

```math
O(x,y)=\sum_i\sum_j I(x-i,y-j)K(i,j)
```

这里不存在“过去”。它表达的是：**周围像素按照卷积核的空间规则，共同决定当前位置的输出。**

![卷积窗口的四个计算步骤](../../docs/assets/chapter01_convolution_intuition.svg)

把卷积核当作一张可重复使用的局部问题：

| 卷积核在问什么 | 输出大的含义 | 典型用途 |
|---|---|---|
| 周围像素的平均值是多少？ | 局部整体亮度 | 平滑、降噪 |
| 左边暗、右边亮吗？ | 竖直方向亮度突变 | 边缘检测 |
| 中心和邻居差别大吗？ | 局部细节突出 | 锐化 |
| 是否像某种纹理？ | 局部模式匹配 | 特征提取 |

图像适合卷积有两个原因：相邻像素通常相关；同一种边缘无论出现在左上还是右下，都应由同一个规则检测。后一性质叫作**平移等变性**：输入平移，响应图也跟着平移。

## 第五层：模糊为什么看起来像“扩散”？

Gaussian 卷积让一个像素的强度分散给邻居。重复进行非常小的 Gaussian 模糊，可以看成图像沿一个“虚拟时间”满足热方程：

```math
\frac{\partial I}{\partial t}=\nabla^2 I
```

这里图像像温度场，亮度从高处向周围扩散。`t` 越大，Gaussian 的 `σ` 越大，图像越模糊。

所以“卷积和时间演变有关”在特定情况下是正确的：某些卷积核是微分方程随时间演化的解。但普通二维卷积仍首先是空间邻域运算，不能把每个卷积都解释为真实时间。

## 第六层：频率视角为什么有用？

任何信号都可以拆成不同变化速度的波。缓慢变化是低频，快速明暗交替是高频。卷积定理说：

```math
\mathcal{F}(x*h)=\mathcal{F}(x)\,\mathcal{F}(h)
```

也就是说，空间或时间中的卷积，等价于频率域中的逐项乘法。

- Gaussian 模糊压低高频，所以细节和噪声变弱；
- 锐化提高部分高频，所以边缘更明显，同时噪声也可能增强；
- 边缘核抑制常量和缓慢变化，突出快速变化。

频率解释不是另一种运算，而是观察同一运算的另一副眼镜。

## 第七层：卷积神经网络在做什么？

传统图像处理中，人手设计 Gaussian、Sobel 等卷积核。卷积神经网络则从数据中学习核的数字。

浅层核常对边缘、颜色变化和简单纹理有响应；更深层把前一层的局部响应继续组合，逐渐表达车轮、车辆或行人。CNN 保留了“局部连接”和“权重共享”两个关键思想，但实际框架多数执行不翻转核的互相关。

因此 CNN 的卷积不是在模拟时间，也不等于某个固定滤波器；它是在整张特征图上重复应用一组可学习的局部规则。

## 三个最常见误区

1. **卷积就是模糊。** 错。模糊只是某类核的效果，边缘、锐化和匹配也能由卷积实现。
2. **卷积一定表示过去影响现在。** 错。只有时间坐标和因果系统才赋予它这种解释。
3. **卷积核识别的是完整物体。** 通常不对。一个小核只看局部；复杂物体来自多层、多位置响应的组合。

## 遇到公式时怎样读？

看到

```math
y[n]=\sum_k x[k]h[n-k]
```

不要先想积分技巧，按下面顺序读：

1. 我现在要计算哪个输出位置 `n`？
2. 第 `k` 个输入 `x[k]` 有多大？
3. 它距离当前输出多远，因此权重 `h[n-k]` 是多少？
4. 把所有输入对当前位置的贡献加起来。

图像公式只是把位置从一个下标扩展为两个下标。

## 自测：真正理解了吗？

1. 为什么均值核权重总和通常等于 1？
2. 为什么权重总和为 0 的核对常量图像输出为 0？
3. 为什么 Gaussian 核翻转前后不变？
4. 为什么锐化也会放大噪声？
5. 图像向右平移后，边缘响应图会发生什么？
6. 为什么远处历史输入是否能影响现在，取决于 `h` 在对应延迟处是否为 0？

如果能用“移动、加权、求和、共享规则”回答这些问题，你已经抓住卷积的核心。
