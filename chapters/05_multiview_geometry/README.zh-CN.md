## 1. 针孔相机模型

世界点 `X=[X,Y,Z,1]ᵀ` 投影为像素 `x=[u,v,1]ᵀ`：

```math
s x = K[R|t]X = PX
```

`K` 包含焦距和主点；`R,t` 把世界坐标变换到相机坐标；`P` 是最终的 `3×4` 投影矩阵。透视除法产生：

```math
u=f_x\frac{X_c}{Z_c}+c_x,\qquad
v=f_y\frac{Y_c}{Z_c}+c_y
```

这说明图像只保留 `X/Z` 与 `Y/Z`，单个像素对应空间中的一条射线，而不是唯一三维点。

## 2. 为什么第二个视角能恢复深度

同一三维点在两个相机中产生两条观测射线。理想情况下，两条射线相交的位置就是三维点；带噪声时，三角化寻找最符合两条射线的点。

对校正后的平行双目：

```math
Z=\frac{fB}{d},\qquad d=u_L-u_R
```

`f` 是像素焦距，`B` 是相机基线，`d` 是视差。远处物体视差更小，因此同样的像素匹配误差会造成更大的深度误差。

## 3. 对极约束与基础矩阵

两个视角中的正确对应满足：

```math
x'^T F x = 0
```

给定左图点 `x`，右图中的对应点必须位于极线 `l'=Fx` 上。于是搜索从整张二维图缩减到一条一维直线。

![双目点和对极线](../../docs/assets/chapter05_epipolar_geometry.png)

参考图使用校正双目，相应极线保持水平。同编号点来自同一三维点；近处点左右位移更明显，远处点视差更小。

## 4. 归一化八点法

每对对应点为 `F` 提供一个线性约束。至少八对点可组成 `Af=0`：

1. 两组像素分别平移到质心；
2. 缩放到平均半径 `√2`；
3. 构造设计矩阵并用 SVD 求最小奇异向量；
4. 对求得的矩阵再次 SVD，把最小奇异值设为 0，强制 `rank(F)=2`；
5. 反归一化并统一矩阵尺度。

归一化不是可选装饰。像素坐标通常数百或数千，直接求解会让设计矩阵条件数变差。

## 5. Sampson 误差

代数残差 `x'^TFx` 会随 `F` 的任意尺度变化，不能直接作为像素距离。Sampson 误差使用两条极线梯度做一阶校正：

```math
e=\frac{(x'^TFx)^2}{(Fx)_1^2+(Fx)_2^2+(F^Tx')_1^2+(F^Tx')_2^2}
```

实践中应把它与 RANSAC 结合，剔除不服从同一相机几何的动态物体和错误匹配。

## 6. 线性三角化

对每一对匹配 `(x,y)↔(u,v)`，由 `x×PX=0` 构造四行齐次方程：

```text
x P₃ − P₁
y P₃ − P₂
u P'₃ − P'₁
v P'₃ − P'₂
```

对这个 `4×4` 系统做 SVD，取最小奇异值对应的齐次向量，再除以最后一个分量得到 `(X,Y,Z)`。

![三角化后的 X-Z 深度图](../../docs/assets/chapter05_triangulated_depth.png)

图中横轴是横向位置 `X`，纵轴是前向深度 `Z`。点旁标签显示真实恢复的米制深度。

## 8. 坐标、单位与参数

| 量 | 单位/约定 | 常见错误 |
|---|---|---|
| 图像点 | `(x,y)=(column,row)`，像素 | 与 NumPy `(row,column)` 混用 |
| 世界点 | `(X,Y,Z)` | 忘记明确坐标轴方向 |
| 焦距 | 像素 | 把毫米焦距直接代入投影公式 |
| 基线 | 米或统一世界单位 | 与三维点单位不一致 |
| `F` | 尺度不唯一、秩 2 | 比较矩阵元素而不先归一化 |
| 深度 | 沿相机 Z 轴 | 与欧氏距离混淆 |

## 9. 与自动驾驶的联系

![计算机视觉算法在自动驾驶场景中的对应关系](../../docs/assets/autonomous_driving_cv_map.png)

图中从近到远的半透明路面带表示深度层级。前车和行人的像素位置只有结合标定、视差与相机几何后，才能转换为可用于安全判断的距离；越远的区域视差越小，深度不确定性越大。

- 双目深度和前车距离估计；
- 视觉里程计中的跨帧三角化；
- 地图点构建和定位；
- 多相机几何一致性检查；
- 车道点投影到地面与鸟瞰视图。

真实系统还必须处理畸变、时间同步、滚动快门、动态物体、遮挡和标定漂移。本章使用已知投影矩阵做三角化；后续会学习从本质矩阵恢复相机相对姿态，再进入 PnP 与视觉里程计。
