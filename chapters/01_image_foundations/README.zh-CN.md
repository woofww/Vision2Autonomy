# 第一章：图像处理基础

[English](README.md) | [简体中文](README.zh-CN.md)

本章建立整个项目后续内容依赖的数值基础。我们将灰度图表示为二维 NumPy 数组，从零实现真正的二维卷积，并在此基础上完成 Gaussian 平滑和图像锐化案例。

## 学习目标

完成本章后，你应该能够：

- 解释卷积与互相关之间的区别；
- 判断卷积核尺寸和边界填充对输出的影响；
- 构造并归一化二维 Gaussian 核；
- 在保持图像尺寸不变的情况下执行线性滤波；
- 使用简单参考算法验证向量化实现的正确性；
- 分析平滑和锐化对噪声、边缘与细节的影响。

前置知识包括 Python 基础、NumPy 数组索引和基本矩阵运算。

## 一、图像的数值表示

八位灰度图的每个像素保存一个强度值：

```text
0   = 黑色
255 = 白色
```

虽然输入通常是 `uint8`，库在计算开始时会立即将其转换为 `float64`。这是因为卷积核可能包含负数或小数：如果直接用 `uint8` 计算，负值会溢出，小数会丢失，结果将不再可信。

只有在保存显示图片时，程序才会将数据裁剪到 `[0, 255]` 并转换回 `uint8`。算法调用者拿到的仍然是未经显示裁剪的浮点结果。

## 二、二维卷积

设输入图像为 `I`，卷积核为 `K`，输出像素可写为：

```text
O[y, x] = sum_i sum_j I[y - i, x - j] K[i, j]
```

表达式中的 `y - i` 和 `x - j` 表示卷积核需要在水平和垂直方向翻转。一些图像库实际执行的是互相关，但习惯上仍将其称为卷积。本项目的 `convolve2d` 会显式翻转卷积核，执行数学定义上的卷积。

当前实现步骤如下：

1. 检查输入是否为二维灰度数组；
2. 要求卷积核的两个尺寸均为奇数，使其具有明确中心；
3. 使用 `reflect`、`edge` 或 `constant` 模式扩展图像边界；
4. 使用 `sliding_window_view` 创建每个局部窗口的只读视图；
5. 使用 `einsum` 将所有窗口与翻转后的卷积核相乘并求和。

默认使用 `reflect` 填充，因为它不会在边缘人为引入一圈黑色像素。不过，没有一种边界假设适合所有任务，调用者应根据实际场景选择。

## 三、Gaussian 平滑

二维 Gaussian 函数为：

```text
G(x, y) = exp(-(x² + y²) / (2 sigma²))
```

对函数离散采样后，需要将卷积核除以所有元素之和，使权重总和等于一。因此，常量图像在 Gaussian 滤波后仍应保持原值，这也是测试套件验证的重要性质。

`sigma` 控制分布宽度：

- 较小的 `sigma` 保留更多细节，但去噪能力有限；
- 较大的 `sigma` 能够消除更多高频噪声，同时也会模糊细边缘；
- 卷积核尺寸需要足够大，才能覆盖 `sigma` 对应的主要权重范围。

## 五、参数说明

| 操作 | 卷积核 | 参数 | 用途 |
|---|---:|---|---|
| Gaussian 平滑 | 5 × 5 | `sigma=1.4` | 抑制噪声，为后续边缘检测做准备 |
| 锐化 | 3 × 3 | 中心权重 `5`，四邻域权重 `-1` | 增强边界附近的局部对比度 |
| 边界填充 | — | `reflect` | 保持图像尺寸并避免黑色外框 |

锐化卷积核为：

```text
[ 0 -1  0]
[-1  5 -1]
[ 0 -1  0]
```

## 六、结果分析

- Gaussian 结果中的平坦区域更加平滑，随机亮暗颗粒明显减少。
- 矩形、圆形和三角形的边界仍然存在，但边缘过渡变宽，说明高频成分受到抑制。
- 锐化结果中的边界对比度更高，但噪声也被同步放大。
- 细亮线在锐化后更加明显，Gaussian 平滑后则略微扩散。
- 三幅图片尺寸完全相同，因为实现采用 same-size 输出策略。

这个结果说明：锐化不是免费的细节恢复，它会同时增强真实边缘和噪声；因此实际视觉流水线通常先平滑，再计算梯度。

## 七、局限与改进方向

- 大尺寸二维卷积计算量较高。Gaussian 核具有可分离性，后续可以优化为两次一维卷积。
- `reflect` 假设图像外部是可见边界的镜像，这在某些真实场景中并不成立。
- 保存展示图时的裁剪会隐藏锐化结果中的负值和大于 255 的响应，数值分析时不应使用裁剪后的 PNG。
- 当前案例只处理灰度图，颜色空间及多通道卷积将在后续内容中展开。
